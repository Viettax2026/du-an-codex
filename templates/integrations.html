Thêm data vào nhóm

Thay ID nhóm bằng ID lấy từ API danh sách nhóm. Mỗi lần tối đa 500 dòng, số điện thoại Việt Nam; dòng lỗi được bỏ qua và trả lý do. Thử trước bằng dry_run: true. Khách hàng mới mặc định đồng ý nhận tin; gửi consent: false nếu không bật nhận tin. Hồ sơ cũ giữ nguyên thông tin; gửi rõ consent: true để cập nhật đồng ý, bỏ trường này để giữ trạng thái cũ.

POST /api/v1/data-groups/{id}/members
Authorization: Bearer <khóa>
Content-Type: application/json
Idempotency-Key: crm-import-001

{
  "data": [{"name": "Khách hàng mẫu", "phone": "0901234567"}],
  "source_name": "CRM",
  "dry_run": true
}

Với lần nhập thật, dùng dry_run: false. Giữ nguyên Idempotency-Key và nội dung khi thử lại cùng một lần nhập để nhận lại kết quả, tránh ghi nguồn lặp. Mỗi lần nhập khác dùng mã mới. Nguồn API xuất hiện trong lịch sử nguồn data.

Media

Tải lên bằng multipart/form-data, trường file, tùy chọn group_id. Hỗ trợ JPG/PNG/WEBP/PDF/MP4 tối đa 10 MB/tệp. Chuyển nhóm bằng JSON {"group_id": 1}, hoặc null để bỏ nhóm. Xóa cần JSON {"confirm_delete": true}; tệp đang dùng trong chiến dịch được giữ lại.

Kết quả và lỗi

Phản hồi JSON gồm status, error_code, message, data. Danh sách phân trang bằng page và per_page (tối đa 100). Lỗi 400: dữ liệu sai; 401: khóa không hợp lệ; 403: thiếu quyền; 404: không tìm thấy; 409: trùng nhóm hoặc xung đột mã nhập; 413: tệp quá lớn; 415: sai định dạng yêu cầu.
